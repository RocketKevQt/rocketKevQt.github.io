  • PeerToChat : Application Qt de chat en pair à pair

    Description :

    Logiciel de discussion en pair à pair, utilisant Qt et TCP/IP. Il permet à deux personnes de se connecter en temps réel pour discuter.


    Objectifs Atteints :

    • Connexion entre deux clients
    • Envoi des messages via TCP
    • Chiffrement des messages en bout à bout via RSA et AES
    • Interface TCP complète avec envoi d'ACK
    • Ajouter le support des réponses aux messages
    • Ajouter le support d'édition des messages
    • Interface Attractive
    • Compilation en Flatpak pour la diffusion de l'application vers d'autres clients
    • Ajouter le support de suppression des messages
    • Ajouter une interface de sélection d'emojis

    Objectifs Actuels :

    • Ajouter le support des réactions
    • Envoyer des médias (Image et Video avec un chiffrement)
    • Ajouter le support des GIFS
    • Ajouter le support des Autocollants
    • Permettre de choisir entre TCP et UDP

    Environnement Technique :

    • C++

Projets Web

Fnap : Faux réseau de partage d’images

Description :

Fnap est une application web de type "réseau social" développée pour apprendre Angular à travers une démarche progressive, basée sur deux cours OpenClassrooms. L'interface sombre et moderne met en avant les images postées par les utilisateurs. Le backend est simulé grâce à JSON Server. Le projet met l’accent sur l’UX (prévisualisation, feedbacks visuels) et une architecture en sous dossiers propre à Angular Standalone.


Technologies Utilisées :
  • Angular 20 (Standalone)
  • TypeScript
  • SCSS
  • HTML5
  • JSON Server (Fake API REST)

Objectifs Atteints :

  • Afficher une liste de contenus depuis une base JSON simulée
  • Créer un post avec image, titre, description et localisation
  • Prévisualisation en temps réel du contenu posté
  • Système de likes persistant
  • Système de fausse authentification (guards + redirection)
